# QuillApex

QuillApex enables high-performance, real-time data processing with automatic schema adaptation, optimizing scalable architecture.

With QuillApex, you get a lightweight tool that stays out of your way.

**What you get**

- QuillApex enables high-performance, real-time data
- processing with automatic schema adaptation,
- optimizing scalable architecture

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/QuillApex.git`
2. `cd QuillApex`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure QuillApex, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
